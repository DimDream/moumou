# 🐄 哞哞庇护所（Moumou Shelter）

一款 2.5D 网页小游戏：点击草地移动小牛，收集草料，回到庇护所过关。

**在线试玩**：https://dimdream.github.io/moumou/

## 玩法

打开 `index.html` 即玩（单文件、three.js 已内联、离线可玩、无需服务器）。

1. 开始界面 → 关卡选择（第一大关 · 1-5 小关，通关自动解锁下一关）
2. 点击草地移动小牛，靠近金色草料堆自动收集
3. 收集 5 份草料后，地图随机位置出现发光的「哞哞庇护所」
4. 抵达庇护所即过关，可进入下一小关

## 五大关

| 关卡 | 名称 | 特色 |
|---|---|---|
| 1 | 青草原野 | 基础玩法，无龙卷风 |
| 2 | 小河绕行 | 河流挡路，只能走小桥过河 |
| 3 | 水网密布 | 多条河，认准一路小桥 |
| 4 | 迷宫探路 | 过小桥进 13×13 随机迷宫，找齐草料和庇护所 |
| 5 | 风雨迷宫 | 同第 4 关 + 刮风、下雨效果与音效 |

## 操作

- 鼠标 / 触屏点击草地：移动
- 滚轮：缩放视角
- R 键：重新开始本关
- M 键：开关音效
- 选关、重开、回菜单均为原地切换（不刷新页面），手机浏览器可正常游玩

## 特性

- 2.5D 视角：3D 场景 + 固定俯角跟随相机，低多边形卡通风格
- 无边界地形：草地无限延伸，可一直往任意方向走
- 树林遮挡：240 棵树木挡住去路，需要绕行
- 小牛头顶 3D 方向箭头：金色指向最近草料、红色指向庇护所
- 小地图：实时显示周边树木、草料、河流、小桥、迷宫墙与龙卷风
- 龙卷风：屏幕内生成、沿直线前进，小牛会被卷入风心、卷上高空并高速自转（无伤害）
- WebAudio 音效：收集、胜利、风声、雨声（可静音）

## 本地开发

改 `_build/moumou_template.html` 顶部的配置区（草料数量、小牛速度、树林密度、龙卷风参数等），然后运行构建脚本重新生成单文件游戏。
