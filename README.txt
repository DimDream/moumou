哞哞庇护所（Moumou Shelter）
================================
一款 2.5D 网页小游戏：点击草地移动小牛，收集草料，回到庇护所过关。

游戏流程
--------
1. 用浏览器（推荐 Chrome / Edge）打开 index.html，双击即可，无需服务器、无需联网。
2. 首次进入是开始界面，点击「开始游戏」进入关卡选择。
3. 第一大关包含 5 个小关，通关后自动解锁下一关（记录保存在本地）。

关卡一览（第一大关）
------------------
- 第 1 小关 · 青草原野：基础玩法，无龙卷风
- 第 2 小关 · 小河绕行：小迷宫，河流是墙、小桥是路，过桥收集草料
- 第 3 小关 · 水网密布：更大的迷宫，多条河交错，认准桥路穿行
- 第 4 小关 · 迷宫探路：树墙河流环绕的大迷宫，找齐草料和庇护所
- 第 5 小关 · 风雨迷宫：与第 4 关相同，外加刮风、下雨的效果和音效

玩法
----
1. 鼠标点击草地任意位置，小牛会自动走过去；树林、河流、迷宫墙都会挡住去路。
2. 地图随机出现金色草料堆（带光环），小牛靠近后自动收集，左上角显示进度。
3. 收集满 5 份草料后，地图随机位置出现发光的「哞哞庇护所」。
4. 点击地面移动小牛，抵达庇护所即过关（结算用时，可进入下一关）。

龙卷风
------
- 第 2-5 小关会有龙卷风：开局约 12 秒后第一场，之后每 20 秒左右一场。
- 龙卷风在屏幕内生成，沿一条直线前进；小牛一旦被卷入风心，会被吸住不停旋转、
  越卷越高，在龙卷风停下之前无法控制——但不会受伤：不扣草料、不会失败。

操作
----
- 鼠标左键 / 触屏点击草地：移动
- 滚轮：缩放视角
- R 键：重新开始本关
- M 键：开关音效（含雨声）
- 选关、重开、回菜单均为原地切换（不刷新页面），手机浏览器可正常游玩

特性
----
- 无边界地形：草地无限延伸，可以一直往任意方向走（右下角实时显示坐标）
- 树林遮挡：树木会挡住小牛，靠近会被推开
- 素材迷宫（第 2-5 关）：同一套迷宫生成器——递归回溯挖出迷宫结构，
  再把「墙」做成河流或树木、「通道」做成小桥（跨河）或空地，
  树墙、水域、小桥与关卡一体生成，不再分开绘制
- 小地图：右上角实时显示周边树木、河流、小桥、草料、庇护所与龙卷风；
  地图方向固定（上方为北、世界 +z 朝屏幕下方），小牛图标箭头随自身朝向旋转
- 头顶箭头：小牛头顶有 3D 方向箭头，金色指向最近草料、红色指向庇护所
- 方向箭头：最近草料、庇护所、龙卷风均有箭头 + 距离提示
- 刮风下雨：第 5 关有雨滴粒子、倾斜风向、阴沉天空与循环雨声音效
- 防卡死：被龙卷风卷进树墙或水里会被自动移到最近可站立格

文件说明
--------

- three.min.js    three.js r158 库文件（index.html 已内联，此处仅作备份）
